## 📈 Мой путь

### Вёрстка и JavaScript

Моё обучение началось с создания сайтов с использованием HTML и CSS. На этом этапе я изучал основы веб-разработки, работу с интерфейсами, адаптивную вёрстку и постепенно переходил к JavaScript.

Это дало мне базовое понимание того, как устроена клиентская часть веб-приложений, ещё до знакомства с React.

### React

Следующим этапом стал React. Я начал с небольших приложений и постепенно знакомился с компонентным подходом, состоянием приложения, хуками, взаимодействием с API и организацией клиентского кода.

Одним из первых заметных проектов стал [social-demo](https://github.com/Allaros/social-demo) — демо-версия мессенджера на React. Сейчас этот проект хорошо показывает начальный этап моего пути и переход от обычной вёрстки к разработке интерактивных приложений.

### Next.js

После React я перешёл к Next.js и начал глубже разбираться в разработке современных веб-приложений. В проекте [next-app](https://github.com/Allaros/next-app) я работал с TypeScript, компонентами, хуками, контекстом, структурой приложения, API и взаимодействием с базой данных.

На этом этапе я начал уделять больше внимания не отдельным компонентам, а организации приложения в целом.

### Full-Stack разработка

Следующим шагом стало создание социальной платформы с отдельными frontend и backend приложениями.

Frontend проекта ([social](https://github.com/Allaros/social)) построен на Next.js, React и TypeScript. Здесь я работал с feature-based архитектурой, управлением серверным и клиентским состоянием, формами, валидацией и WebSocket-коммуникацией.

Backend ([social-backend](https://github.com/Allaros/social-backend)) стал моим переходом к более серьёзной серверной разработке. Я начал работать с NestJS, PostgreSQL и TypeORM, реализовывать аутентификацию, REST API и real-time взаимодействие через WebSocket. В проекте также использовал Redis и событийную архитектуру.

Этот этап был особенно важен для меня, потому что позволил перейти от разработки отдельных частей приложения к пониманию их взаимодействия в рамках единой системы.

## 💡 Что мне интересно

Сейчас мне одинаково интересны **Frontend и Backend разработка**. Мне нравится работать как над пользовательским интерфейсом и взаимодействием с ним, так и над серверной частью, API, базами данных и бизнес-логикой.

Мне интересно понимать приложение целиком и то, как отдельные его части взаимодействуют между собой. На frontend мне особенно интересны React и Next.js, управление состоянием и данными, а на backend — NestJS, PostgreSQL, Redis и построение хорошо структурированных API.
